# RaceX Server

Express + Socket.io (Node.js >= 20).

## Local
```bash
npm install
npm start      # porta 3000 (ou PORT)
npm test
```

Variáveis opcionais: `PORT`, `MAX_ROOMS` (padrão 100), `MIN_PLAYERS` (padrão 2).

## Render
- New > Web Service, Root Directory `server`.
- Build: `npm install` | Start: `npm start`.
- O Render define `PORT` automaticamente.
